# 엔진글리시 — 학습자 응답 이해 LoRA 평가 (2026-11-15)

운전 중 영어 학습에서 차량 STT(영어)가 돌려준 학습자 발화를 문항과 함께 받아
행동(답변·다시 듣기·건너뛰기·힌트·뜻·일시정지·재개·종료·잡음)과 판정(정답·부분 정답·오답),
오류 유형(한국어 화자 발음 혼동 R/L·F/P·V/B·TH·SH/S·받침 탈락, 관사·시제·복수·전치사·어순·누락)을 JSON 한 줄로 내는 모델이다.
앱에서는 규칙 엔진이 먼저 판정하고 애매할 때만 이 모델을 부르는 보조 역할이다.

- 데이터: `ml/english/gen_en.py` 합성 데이터 — 문항 씨앗 112개(90개 학습용, 22개는 시험 전용 unseen), train 5,460 / valid 300 / test 657
- 학습: LoRA r16/α32(모든 선형층), 2 epoch, 배치 8×누적 2, max_len 320, bf16, gradient checkpointing — NHN Cloud **B200 MIG 1g.23gb**
- 평가: `ml/english/eval_en.py` (탐욕 디코딩). '완전 일치'는 행동·판정·정답 번호·오류 유형이 모두 같은 경우

## 결과 (test 657문항)

| 모델 | 행동 정확도 | 판정 정확도 | 완전 일치 | 오류 유형 F1 | 처음 보는 문항 판정 | 학습 시간 | 지연(배치 1) |
|---|---|---|---|---|---|---|---|
| 규칙 기반 비교군 | 93.3% | 75.9% | 69.9% | 55.8% | 77.5% | – | <1 ms |
| **Qwen3-4B + LoRA** | **99.5%** | **96.6%** | **95.3%** | **91.1%** | **97.2%** | 15.0분 | 594 ms (bf16, MIG 1/7) |
| Qwen3-1.7B + LoRA | 99.8% | 94.6% | 92.5% | 84.4% | 93.0% | 7.4분 | 392 ms (bf16, MIG 1/7) |

검증 손실: 4B 0.0031, 1.7B 0.0061. 학습 문항(seen)만 보면 1.7B가 조금 높고(판정 96.7% vs 95.8%), **처음 보는 문항(unseen)에서는 4B가 확실히 앞선다**(판정 97.2% vs 93.0%, 완전 일치 95.5% vs 89.2%).

### 선택
- **기본 모델은 Qwen3-4B + LoRA**: 처음 보는 문항과 발음 오류 진단에서 크게 앞선다. 학습 서비스의 핵심인 '어디가 틀렸는지'를 짚는 능력이 중요하다.
- **Qwen3-1.7B + LoRA는 경량 대안**: 지연이 34% 짧고(392 ms vs 594 ms) 잡음·엉뚱한 답 구분은 오히려 낫다. 사양이 낮은 헤드유닛이나 빠른 1차 판정용으로 쓴다.

## 한계
- **합성 데이터 평가**다. 시험의 절반 이상은 학습에 없는 문항이지만, 발화 변형은 같은 생성 규칙에서 나온다. 실제 차량 STT 출력과 실제 학습자 발화로 다시 평가해야 한다(2차 PT 전 계획).
- 지연 594 ms는 B200 1/7 조각에서 bf16 기준이다. 차량에서는 4비트 GGUF(llama.cpp)로 변환해 다시 측정한다. 앱은 규칙 엔진이 먼저 판정하고 애매한 경우에만 모델을 부르므로 대부분의 응답은 모델 지연 없이 처리된다.
- 아직 앱에 탑재하지 않았다(앱은 규칙 엔진으로 동작).
- 평가 수치는 앱 이름을 바꾸기 전의 시스템 프롬프트(첫 구절의 앱 이름만 다름)로 학습·평가한 결과다. 지금 저장소의 `gen_en.py`로 다시 만들면 같은 절차로 재현된다.
