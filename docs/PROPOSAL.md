## 1. 앱 한 줄 소개

**기어·도어·배터리·충전·경고등 같은 차량 이벤트로 먼저 움직이는 AI 동승 에이전트 — "운전대 밖의 일은, 옆자리가."**
충전·휴식 통합 계획, 단계별 졸음 케어, 펫·휴식 케어, 아이 동승, 주차 위치 기억, 경고등 해설을 차량 기본 AI(Gleo)와 연동되는 하나의 대화형 경험으로 제공합니다.

## 2. 기획 배경

### 2-1. 주목한 순간: "말해야 움직이는 비서"의 한계
- 차량 음성비서는 10년 넘게 J.D. Power 품질조사 상위 불만 항목입니다. 2026년 IQS에서도 인포테인먼트는 유일하게 품질이 **악화**된 분야였고, 주의분산 불만의 46%가 터치스크린이었습니다.
- 2026년 출시된 Gleo AI 시승기에서도 "엉뜨 켜줘" 같은 구어를 이해하지 못하고, 호출어와 지연이 불편하다는 지적이 나왔습니다. 운전자는 몇 달 지나면 음성 명령을 쓰지 않게 됩니다.
- 핵심 통찰: **운전자는 '명령'을 원하지 않습니다. 필요한 순간을 차가 먼저 알아채기를 원합니다.** 그 순간은 언제나 차량 이벤트(기어 D 진입, 배터리 부족 예측, 연속 주행 2시간, P 기어 후 운전석 문 열림, 경고등 점등)와 함께 옵니다. 이것은 휴대폰 앱이 결코 알 수 없는 신호입니다.

### 2-3. 왜 지금, 왜 차 안에서 해결해야 하는가
- 폰 기반(Android Auto/CarPlay) 앱은 **실제 배터리 SOC·기어·도어·경고등을 모르고**, 운전자가 내리면 동작하지 않습니다. 펫 케어·뒷좌석 확인·충전 과태료 타이머는 **차가 주체**여야만 가능합니다.
- Pleos Connect는 Vehicle·NaviHelper·STT/TTS SDK와 Gleo App Schema를 열었습니다. 차량 데이터를 이해하는 **한국어 도메인 에이전트**가 들어갈 자리가 생겼습니다.

## 3. 앱 주요 기능 및 차량 특화 요소

### 3-1. 컨셉: 이벤트 기반 도메인 에이전트 + Gleo 연동
옆자리는 범용 비서를 하나 더 만드는 대신, **Gleo가 '말하면 하는' 비서라면 옆자리는 '말하기 전에 챙기는' 동승자**를 지향합니다.
- **컨텍스트 엔진**: 차량 신호, 경로, 시간, 동승 구성을 하나의 `DriveContext`로 합쳐 **모먼트(선제 제안)**를 만듭니다.
- **인터럽션 매니저**: 다음 회전까지의 거리(NaviHelper TBT)와 차속으로 운전 부하를 추정합니다. 회전 직전이나 혼잡 구간에서는 비긴급 음성을 보류합니다. 안전 알림은 보류하지 않습니다.
- **하이브리드 AI**: 단순 명령은 온디바이스 SLM이 300ms 안에, 오프라인에서도 처리합니다. 다중 제약 계획·진단·루틴 생성만 자체 추론 LLM으로 보냅니다. 모든 응답에 **처리 위치(온디바이스/클라우드/안전 규칙)**를 표시해 신뢰를 줍니다.
- **Gleo App Schema**: "글레오야, 옆자리로 강릉 가는 충전 계획 세워줘"라고 말하면 차량 기본 AI가 옆자리 기능을 Function Calling으로 직접 호출합니다(`PLAN_EV_TRIP`, `START_CARE_MODE`, `DIAGNOSE_VEHICLE`).

### 3-2. 핵심 기능
| 기능 | 해결하는 문제 | 차량 특화 요소 (트리거 → 행동) |
|---|---|---|
| ⚡ **충전 코파일럿** | 도착 직전 배터리 불안, 고장 충전기, 연휴 대기 | 경로 설정 시 **실제 SOC·외기온·공조 부하**로 도착 SOC를 예측합니다(NaviHelper `TripInfo.estimatedSocAtDest`와 교차검증). 12% 미만이면 충전과 휴식을 묶은 계획을 제안하고 경유지를 추가합니다. 충전소마다 **신뢰도 점수**(최근 세션 경과 + 30일 고장 제보 + 가용 비율)를 매기고, **예비 충전소를 항상 확보**하며, 멤버십 실결제가와 대기 예측을 함께 보여 줍니다 |
| ⏱ **충전 세션 케어** | 과태료, 지하주차장 충전 제한 | 충전 스위치 ON 감지 → **1시간 과태료 타이머**(50분에 음성 알림), 완료 예상 시각, 쉼 모드·아이 퀴즈 연결. **`setEvChargePercentLimit`로 지하주차장 90% 한도** 설정 |
| 😴 **단계별 졸음 케어** | 경고음만으로는 쉬지 않음 | 연속 주행 시간(Odometer)·생체리듬 시간대·고속 단조 주행·내기순환으로 **설명 가능한 졸음 점수**를 냅니다. 1단계 환기+온도 낮춤(HVAC 제어) → 2단계 **대화로 깨우기**(LLM) → 3단계 **졸음쉼터 경유 + 15분 쉼 모드** |
| 🐶 **펫 케어 모드** | 잠깐 차에 둔 반려견 | P 기어 + 운전석 문 열림 + 극한 외기온 → 제안. 실내 온도 유지, 창밖에서 보이는 **외부 안내 화면**, **배터리 하한 20%·최대 60분** 안전 원칙. Gleo로도 시작 가능 |
| 👨‍👩‍👧 **아이 동승** | "아직 멀었어?", 지루함, 휴식 | 뒷좌석 탑승 감지(Seat) → "만화 n편 보면 도착", 목적지 연계 음성 퀴즈(운전자는 음성만 들음), 아이 맞춤 휴게 제안 |
| 🚸 **뒷좌석 확인** | 아이 하차 누락 | 출발 시 뒷문 개폐 이력 + 도착 후 뒷문 미개폐 + 운전석 문 열림 → **안전 규칙 엔진** 리마인더 |
| 🅿 **주차 위치 기억** | 지하주차장 위치 오차 | P 기어 + 위치 신호 상실(FusedLocation) → "지하 3층 C-12" **음성 메모**(STT) |
| 🩺 **차량 닥터** | 경고등 불안, 긴 매뉴얼 | 경고등(TPMS·12V·워셔액 등, Safety Telltales)에 실시간 맥락(외기온·점등 시점)을 더해 원인을 추론합니다. 예: "영하의 아침이라 공기 수축 가능성↑, 펑크 배제 불가" → 공기 주입소 경유. 매뉴얼은 RAG 기반 Q&A |
| 🗓 **출근 브리핑·루틴** | 매일 반복되는 설정 | D 기어 + 평일 아침 → 회사 안내·예열·30초 브리핑. **"평일 8시에 출발하면 회사 안내하고 21도로"처럼 말로 루틴을 만들면** 조건·동작으로 구조화 |

### 3-3. 차량 환경만의 UX
- **주행 중 글랜스 모드**: CarUxRestrictions를 따라 카드 1장, 큰 수치 1개, 대형 버튼 3개만 보여 줍니다. 키보드·장문·대기 애니메이션은 끄고, 영상 요청은 안전 정책으로 차단합니다.
- **음성 자막 스트립**: 응답을 상태바 안에 표시해 콘텐츠를 가리지 않습니다.
- **반응형 폼팩터**: 12.9″~17″, 2,560dp 가로 전체부터 반쪽 세로 창까지 대응합니다. 버튼은 최소 76dp, 본문은 20sp 이상입니다.

## 4. 주요 사용 시나리오

**① 평일 아침 — 서준(38, 판교 출근, 전기차)**
07:46 P → D. 옆자리가 루틴대로 회사 안내를 걸고, 21°C 예열이 이미 끝나 있습니다. *"좋은 아침이에요. 회사까지 41분, 첫 일정은 10시 회의예요."* 탄천변 사고로 정체가 13분 늘자 *"분당수서로로 우회하면 6분 빨라요"*라고 제안합니다. 회전 800m 전에는 말을 아낍니다(인터럽션 매니저). 지하주차장에서 GPS가 끊기면 *"주차 위치 기억할까요?"* → "지하 3층 C-12".

**② 연휴 가족여행 — 강릉, 아이 2명(7·5세)**
영동고속도로 주행 중, 옆자리가 먼저 말을 겁니다. *"이대로면 도착 시 배터리 2%예요."* "충전이랑 쉬는 거 같이 해결해줘" → 클라우드 추론이 충전소 3곳을 비교합니다(출력·가용·신뢰도·키즈 공간). **횡성휴게소 E-pit에서 18분 충전 + 간식·화장실** 계획을 세우고, 확인 한 번에 차량 내비에 경유지가 들어갑니다. 충전 중에는 과태료 타이머가 돌고, 뒷좌석 아이들은 *"바다 동물 퀴즈"*를 합니다. 출발 92분째, 아이들이 지루해할 시간도 챙깁니다.

**③ 오후 고속도로 — 연속 2시간 단독 운전**
졸음 점수가 62에서 90으로 오릅니다. 바깥 공기를 넣고 온도를 낮추고, 짧은 대화로 깨운 뒤 *"4.2km 앞 졸음쉼터에서 15분만 쉬어 가요"* → 경유지 추가, 쉼 모드로 시원하게 깨웁니다.

**④ 한여름 휴게소 — 반려견 '콩이'**
P 기어, 31°C, 운전석 문 열림 → *"콩이를 두고 내리시나요?"* → 펫 케어 22°C 유지, 창에는 **"반려견이 안전하게 쉬고 있어요"** 대형 안내. 운전 중이었다면 "글레오야, 옆자리 펫 케어 켜줘"로도 시작됩니다.

**⑤ 영하의 출근길 — TPMS 경고등**
점등 즉시 *"기온이 -3°C로 떨어진 아침엔 공기압이 함께 내려가 경고가 뜨는 경우가 많아요. 다만 펑크일 수도 있어요"* → 1.8km 앞 무료 공기 주입소 경유. 다시 켜지면 서비스센터 예약을 안내합니다.

**⑥ 하원길 도착** — 출발 때 열린 뒷문이 도착 후 열리지 않았는데 운전석 문이 열리면 → *"잠깐만요! 뒷좌석에 하율이 있는지 확인해 주세요."*

## 5. 개발 계획 (Pleos Connect 구현 범위 · SDK/API 사용 계획)

### 5-1. 현재 개발 상태 (1차 제출 시점)
- **Kotlin + Jetpack Compose 네이티브 앱**, release APK 서명 완료
- **Pleos Connect 에뮬레이터 v2.1.0**(2560×1440, 160dpi)에서 구동 검증 완료
  - Virtual Console 기어 D → CarUxRestrictions 수신 → 글랜스 모드 전환 확인
  - AI 확인 → `NaviHelper.addWaypoint` → **기본 내비 앱이 경유지 요청 수신** (로그 확인)
  - 응답 음성 → **Pleos 온디바이스 TTS 출력** 확인
  - 펫 케어 → `setHvacTemperature` → **에뮬레이터 공조 온도 실제 변경** 확인
  - Gleo 액션 Intent → 처리 → `APP_ACTION_RESPONSE` 콜백 → **Gleo 서비스 수신** 확인
- 시연 디렉터(8개 시나리오)로 Virtual Console에 없는 신호(차속·경로 진행·시간 흐름)를 재현합니다

| **AAOS Car API** | `PERF_VEHICLE_SPEED`, `ENV_OUTSIDE_TEMPERATURE`, `RANGE_REMAINING`, `EV_BATTERY_INSTANTANEOUS_CHARGE_RATE`, **CarUxRestrictionsManager** | 주행 판단, 에너지 모델, 주의분산 최적화 |
| **Gleo Interface (App Schema)** | `assets/schema.json` 3개 액션, Intent `ACTION_PARAM` 수신, `APP_ACTION_RESPONSE` 콜백(7초 이내) | Gleo에서 옆자리 호출 |

### 5-3. AI 개발 로드맵 (현재 미탑재 → 동일 인터페이스로 교체)
| 계층 | 1차(현재) | 2차 PT(~12/3) | 출시 |
|---|---|---|---|
| 온디바이스 의도·라우팅 (`OnDeviceIntentEngine`) | 규칙 기반 대체 구현 | 경량 의도분류 모델(int8, ~50MB) | 차량 도메인 한국어 SLM 1~3B **4bit 양자화**(NPU) 또는 Pleos LLM SDK `ON_DEVICE` |
| 추론 LLM (`CloudReasoner`) | 컨텍스트 반영 시나리오 응답 | 자체 서버 프로토타입(Tool-use) | 차량 도메인 SFT + Tool-use LLM, 개인정보 최소화 입력 |
| 컨텍스트 엔진 | 설명 가능한 규칙 트리거 | 사용자 피드백 로그 수집 | SLM 재순위화·개인화 문구 |
| 학습 데이터 | — | Tool 스키마 × 시나리오 × 구어 변형("엉뜨", "히터 좀") 합성 데이터 | 동의 기반 실사용 로그로 지속 학습 |

- **평가 지표**: 의도 정확도, 슬롯 F1, 라우팅 정밀도(불필요한 클라우드 호출률), Tool 호출 유효성, p95 지연(엣지 <300ms, 클라우드 <2.5s), 모먼트 수락률

## 6. 기대효과 및 발전 가능성

### 6-1. 사용자 가치
- **안전**: 졸음 단계별 케어, 운전 부하에 맞춘 알림, 뒷좌석 확인, 주행 중 영상 차단
- **시간·비용**: 충전 실패와 대기, 과태료를 피하고, 매일 하던 출퇴근 설정을 자동화
- **마음의 여유**: 반려견, 아이, 주차, 경고등처럼 운전 중 머릿속을 차지하던 걱정을 줄임

### 6-2. 타깃 고객
| 세그먼트 | 규모 (근거) | 핵심 기능 |
|---|---|---|
| EV 오너 | 국내 누적 109.5만 대(2026.6), 2026 상반기 신차의 23% | 충전 코파일럿·세션 케어 |
| 출퇴근 운전자 | 수도권 출퇴근 왕복 83.2분 | 루틴·브리핑·주차 메모 (**매일 사용**) |
| 아이 동반 가족 | 18세 미만 자녀 부부 가구 378.5만 | 가족 장거리·뒷좌석 확인 |
| 반려동물 가구 | 591만 가구(26.7%) | 펫 케어 |

- 진입 시장: 국내 Pleos Connect 탑재 현대·기아·제네시스 차량(2026 그랜저→아반떼·투싼으로 확대, 2030년 2,000만 대 탑재 목표). 현대차그룹 국내 판매 약 110만 대/년.

### 6-3. 예상 MAU (가정 명시)
| 연도 | Pleos 탑재 국내 누적(가정) | 설치율 | MAU/설치 | **예상 MAU** |
|---|---|---|---|---|
| 2027 | 80만 대 | 15% | 65% | **약 7.8만** |
| 2028 | 180만 대 | 22% | 65% | **약 25.7만** |
| 2029 | 300만 대 + 해외 | 30% | 65% | **약 58만+** |

- **MAU/설치율 65%의 근거**: 사용자가 앱을 '여는' 구조가 아니라 **차가 이벤트마다 부르는** 구조입니다(D 기어 진입마다 루틴과 브리핑, 충전마다 세션 케어).
- **Retention 목표**: D30 45%, M6 35%(일반 모바일 앱 D30 5~10% 수준 대비). 출퇴근은 매일, 충전은 주 1회 이상 반복 트리거가 발생합니다.
- 비교 기준: 내비 1위 Tmap MAU 1,468만(2026 상반기). 차량 이벤트 기반 앱의 성장 천장을 가늠하는 참고치입니다.

### 6-4. 수익 모델 (운전자 무료 + B2B2C)
운전자의 76%가 제조사 구독을 거부한다는 조사에 따라 **기본 기능은 무료**로 둡니다.
1. **충전 사업자(CPO) 제휴**: 추천·예약·로밍 결제 수수료, 신뢰도 데이터 피드백
2. **휴게소·F&B·주차 제휴**: 충전 대기 시간 쿠폰, 지하주차장 연동
3. **보험사 UBI**: 동의 기반 안전 점수(졸음 케어 수락률·급제동)로 안전운전 특약 할인
4. **선택형 프리미엄 '패밀리 플러스'**: 키즈 오디오 스토리·퀴즈 팩, 펫 케어 원격 알림 확장
5. **OEM 라이선스**: 컨텍스트 엔진·차량 도메인 SLM을 Gleo 생태계에 기능 모듈로 공급

### 6-5. 서비스 확대 계획
- **2027 H1**: Pleos App Market 국내 출시, 충전소 실시간 API·결제 연동
- **2027 H2**: 자체 SLM 탑재 / Pleos LLM SDK 공개 시 즉시 연동(인터페이스 동일), 휴대폰 동반 앱(펫 케어 원격 확인, 주차 위치 전송)
- **2028**: 유럽·북미 진출(지역별 주의분산 정책 대응, 북미는 음성 전용 UX), 상용·플릿(배송 기사 졸음·충전 관리), 렌터카·카셰어링
- **장기**: DMS 카메라·조향 패턴 기반 졸음 모델 고도화, V2G·홈 충전 연계, 차량 간 충전소 신뢰도 공유 네트워크
